SPIRE is highly extensible via a plugin framework that allows many core operations to be added and customized. This page describes the types of plugins available, how to integrate plugins while deploying SPIRE, and has a link to the SPIRE Plugin SDK for those interested in authoring a plugin. Authoring SPIRE plugins Refer to the SPIRE Plugin SDK GitHub page for documentation and templates that you can use to code your own SPIRE plugins.
